# Smart File Organizer 📁

A simple and useful file organization tool built with Go.

Smart File Organizer automatically sorts files into folders based on
their file type.

## ✨ Features

- Automatically organizes files
- Images detection
- Videos detection
- Audio detection
- Documents detection
- Spreadsheet detection
- Presentation detection
- Archive detection
- Source code detection
- Unknown files go into `Others`
- Duplicate filename protection
- Dry-run preview mode
- Lightweight and fast
- Built with pure Go
